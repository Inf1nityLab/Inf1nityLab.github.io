Сделай сайт-меню для кафе. Его откроют гости с телефона, главное — быстро заказать. Пример: скрин. Ответ: код одним файлом. Готово, если есть корзина. Сначала задай вопросы и покажи план. Кафе үчүн сайт-меню жаса. Аны коноктор телефондон ачат, эң негизгиси — тез заказ берүү. Мисал: скрин. Жооп: бир файлдагы код. Даяр, эгер себет болсо. Адегенде суроо берип, планды көрсөт.

Промпт по дизайну Дизайн боюнча промпт

Вот дизайн моего приложения: картинки экранов. Сделай точно по дизайну. Приложение — запись к мастеру: клиент выбирает время, мастер видит записи. Стек: Flutter + Supabase. Экраны: вход, список, запись, профиль. Сначала покажи план, потом делай по одному экрану. Мына менин колдонмомдун дизайны: экрандардын сүрөттөрү. Так дизайн боюнча жаса. Колдонмо — чеберге жазылуу: кардар убакыт тандайт, чебер жазылууларды көрөт. Стек: Flutter + Supabase. Экрандар: кирүү, тизме, жазылуу, профиль. Адегенде планды көрсөт, анан бир-бир экрандан жаса.
